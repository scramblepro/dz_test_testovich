# README: Тестирование API Яндекс.Диска (Python + unittest)

# Скрипт автоматизирует тестирование API Яндекс.Диска. Используется модуль unittest для написания тестов и requests для отправки HTTP-запросов.

# Проверяются следующие сценарии:

## test_create_folder	              Позитивный кейс: создание новой папки.
## test_create_existing_folder	      Негативный кейс: попытка создать уже существующую папку.
## test_create_folder_invalid_name	  Негативный кейс: создание папки с некорректным именем.

# После каждого теста создаётся и удаляется папка, чтобы не оставлять мусор. Для запуска должен быть установлен Python 3.6+
# Установлена библиотека requests
# Создан файл OAuthtoken.py с содержимым:

##   token = "OAuth YOUR_YANDEX_DISK_TOKEN" где YOUR_YANDEX_DISK_TOKEN - ваш рабочий OAuth-токен от Яндекс.Диска.

# Запуск: python test_yadisk.py
